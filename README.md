# 🤖 Telegram-бот Студент Мбапенко

---



## 🛠 Стек технологий

* **Платформа:** Google Apps Script (JavaScript)

* **База данных:** Google Sheets

* **API:** Telegram Bot API (работает через Webhook)

* **Локальная разработка и деплой:** Node.js + `@google/clasp`



---



## 📂 Структура проекта

* `Code.js` (или ваши основные файлы логики) — обработка входящих сообщений, проверка прав администратора, чтение/запись в таблицу.

* `config.example.js` — шаблон конфигурации.

* `config.js` *(в `.gitignore`)* — ваши локальные секреты (токен бота, ID чата, название листа).

* `appsscript.json` — манифест проекта Google Apps Script.

* `.clasp.json` *(в `.gitignore`)* — привязка локальной папки к вашему тестовому проекту в Google Apps Script.

## 🚀 Как развернуть проект для разработки (своя песочница)



Чтобы не сломать основного бота группы во время тестов, каждый разработчик поднимает свою локальную копию.



### 1. Подготовка окружения

Убедитесь, что у вас установлены **Git** и **Node.js** (версии LTS). Установите утилиту `clasp` глобально:

```bash

npm install @google/clasp -g

```

Включите **Google Apps Script API** в настройках своего аккаунта Google: [script.google.com/home/users/settings](https://script.google.com/home/users/settings).



### 2. Клонирование репозитория

```bash

git clone https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git

cd НАЗВАНИЕ_РЕПОЗИТОРИЯ

```



### 3. Создание тестового бота и таблицы

1. Создайте своего тестового бота в Telegram через [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируйте его **Token**.

2. Сделайте копию [шаблона Google Таблицы](#) *(вставьте сюда ссылку на пустую копию таблицы без личных данных)*.

3. В скопированной таблице перейдите в **Расширения → Apps Script**, откройте **Настройки проекта (⚙️)** и скопируйте **Идентификатор скрипта (Script ID)**.



### 4. Настройка локальных файлов

1. Скопируйте `config.example.js` и переименуйте его в `config.js`.

2. Впишите в `config.js` токен вашего тестового бота, ID тестового чата и имя рабочего листа:

   ```javascript

   var TOKEN = "ВАШ_ТЕСТОВЫЙ_ТОКЕН";

   var CHAT_ID = "ID_ТЕСТОВОГО_ЧАТА";

   var SHEET_NAME = "Лист1";

   ```

3. Авторизуйтесь в `clasp` и привяжите ваш тестовый скрипт:

   ```bash

   clasp login

   clasp clone "ВАШ_ТЕСТОВЫЙ_SCRIPT_ID"

   ```

   *(Если `clasp clone` скачает стандартный пустой `Код.gs` из новой таблицы, просто удалите его, чтобы остались файлы из репозитория).*



### 5. Запуск и деплой

1. Отправьте код из репозитория в ваш Google Apps Script:

   ```bash

   clasp push

   ```

2. Откройте редактор в браузере (`clasp open`), нажмите **Начать развертывание → Новое развертывание** (тип: *Веб-приложение*, доступ: *Все*), скопируйте URL веб-приложения и привяжите Webhook к вашему тестовому боту.

## 🤝 Как добавить новую фичу (Workflow)



Мы работаем через ветки и Pull Request'ы, чтобы код в `main` всегда оставался рабочим:



1. **Создайте новую ветку** под свою задачу:

   ```bash

   git checkout -b feature/название-фичи

   ```

2. **Напишите код** и проверьте его работу в своем тестовом боте, загружая изменения командой `clasp push`.

3. **Зафиксируйте изменения** (убедитесь, что `config.js` и `.clasp.json` не попали в коммит):

   ```bash

   git add .

   git commit -m "feat: краткое описание новой фичи"

   ```

4. **Отправьте ветку на GitHub:**

   ```bash

   git push origin feature/название-фичи

   ```

5. Откройте репозиторий на GitHub и создайте **Pull Request** в ветку `main`. После проверки код будет смержен и задеплоен в основного бота группы!

## ⚠️ Правила безопасности

* **Никогда** не добавляйте реальные токены и ID чатов в `config.example.js` или файлы логики.

* Не удаляйте `.gitignore` — он защищает ваши локальные ключи от случайной публикации.
